# AURA Glossary

## NPU

NPU means **Neural Processing Unit**. It is a specialized processor designed to accelerate machine-learning inference efficiently, often using less power than running the same workloads on a general-purpose CPU. In AURA, Qualcomm Hexagon NPU hardware accelerates workloads such as YOLO vision detection and local model inference when a compatible QAIRT/Genie deployment is available.

## Event

An Event is AURA's shared record of something perceived, spoken, remembered, or enacted. Vision and speech produce Events; memory stores them; the agent reasons over them.

## HTP

HTP means **Hexagon Tensor Processor**, the Qualcomm accelerator target used by supported NPU deployments in this project.

## Grounded Answer

A grounded answer is generated only from the Events and Knowledge sources retrieved for the user's question. Documentation answers should identify their source file when possible.
