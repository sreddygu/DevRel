## Containerize (runc OCI bundle)

The reference apps deploy as runc OCI bundles (not raw IPK). The
`Dockerfile` here is `FROM scratch` — only the binary goes in.
At `runc start`, `oci_config.json` bind-mounts the host gateway's
`/lib`, `/usr/lib`, `/etc/license`, `/etc/softsku-qwin-agent`, and
the `/dev/lm_device` (license manager device) into the container.

A typical packaging step (matches the reference's
`build_containers.sh`):

```bash
docker build --platform linux/arm64 -t stc_classifier:latest .
docker save -o stc_classifier-docker-image.tar stc_classifier:latest
mkdir runc_bundle && cd runc_bundle
mkdir rootfs && cd rootfs
docker export $(docker create stc_classifier:latest) | tar -xf -
cd ..
cp ../config/oci_config.json config.json
tar czf ../stc_classifier-runc.tar.gz .
```

## Customization checkpoints

1. **`src/tensor_io.c`** — `prepare_inputs()` writes a deterministic
   byte pattern; `consume_outputs()` prints first-8-bytes hex digest.
   Replace with your app-specific data pipeline.
2. **`src/model_inferencing.c`** — single-model state today. To load
   multiple models (e.g. one per WLAN band), parameterize on a band
   id and replicate the static state.
3. **`config/service.json`** — adjust `restart_policy`,
   `keepalive_*`, `license_features`.
4. **`config/oci_config.json`** — add bind-mounts your app needs
   (e.g. `/etc/stc_classifier` is already there for app config).
