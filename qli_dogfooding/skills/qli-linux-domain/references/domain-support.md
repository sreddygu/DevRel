# QLI Linux Support Context

## Supported Scope

- IQ8 and IQ9 QLI devices running supported Linux images.
- Equivalent Linux-based QLI targets when their access, media, AI, and debug
  tools are discovered and validated on the actual device.
- Host environments that provide the tools required by the selected skill.

## Required Discovery

Before execution, determine the device identity, installed image, network path,
SSH access, available peripherals, and AI runtime. Do not reuse paths, device
nodes, model identifiers, or endpoint names from a previous target.

## Evidence Standard

Completed results require objective command or artifact proof. A tool being
installed, a file existing, or a command being proposed is not completion.

## Ownership

QLI dogfooding maintainers own this domain context. Technology owners remain
responsible for the underlying platform documentation and supported versions.
